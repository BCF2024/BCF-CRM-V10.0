BEARCREST GOOGLE FORMS SETUP – VERSION 13.0.0

1. Upload all CRM files to the GitHub repository root.
2. Replace the Apps Script code with BearCrest_Cloud_Connector.gs and deploy a new web-app version.
3. Open the CRM > Settings > Google Forms Application.
4. Click Create BearCrest Google Form once.
5. Google creates the application form and linked response spreadsheet.
6. Save Settings.
7. Use Sync Google Forms to import new responses.
8. Existing imported JotForm records remain visible, but no JotForm API subscription is required.
