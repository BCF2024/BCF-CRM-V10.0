BearCrest JotForm Address Autocomplete Setup

The client-facing application must be updated in JotForm itself. The CRM cannot silently change a live JotForm from the GitHub files.

Recommended setup:
1. Open the BearCrest investor application in JotForm Builder.
2. Select the Property Address question.
3. Use JotForm's Address element rather than a single plain-text field.
4. Turn on address autocomplete / address suggestions in the field properties when available.
5. Keep Street Address, City, State and ZIP enabled and required.
6. Add a separate optional Unit / Suite field.
7. Submit one test application and verify the CRM receives a complete standardized address.

Important: Do not remove or rename the existing property-address question until a test submission confirms the CRM mapping. If you replace it, keep the label clearly containing “Property Address” so Version 10 can recognize it.
