BEARCREST CRM — LENDER PAGE FIX

This build moves the complete lender-management module out of Settings and onto the main Lenders page.

WHAT CHANGED
- Clicking Lenders now opens the working lender database.
- Add, edit, activate/deactivate, reorder, and BearCrest notes are available on the Lenders page.
- The lender module was removed from Settings.
- The service-worker cache name was updated to help devices load the corrected version.

INSTALLATION
Upload all files in this ZIP to the same GitHub Pages repository, replacing the current files. If the old screen appears, refresh the page or close and reopen the installed app once so the new service worker activates.
