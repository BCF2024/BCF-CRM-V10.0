BearCrest CRM V6.3 Mobile Usability Upgrade

This package preserves the V6 desktop layout and adds a dedicated mobile usability pass:
- Full-height, vertically scrollable hamburger navigation
- Reliable bottom navigation and New Loan buttons
- Normal page scrolling
- Compact mobile pipeline columns and cards
- Shorter horizontal drag distances
- Stage selector on every mobile pipeline card as an easier alternative to dragging
- Desktop layout and behavior remain unchanged

Recommended deployment: upload to a test branch first, then replace the existing repository files after verification.
