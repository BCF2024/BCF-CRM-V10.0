BEARCREST CRM VERSION 6.8 UPDATE

WHAT CHANGED
- Restored a visible INSTALL APP button so the CRM can be used both in the browser and as an installed desktop/mobile app.
- Added an interactive comparable-sales map using OpenStreetMap.
- Automatically ranks RentCast comps as Best, Acceptable, or Weak.
- Added checkboxes to exclude comps and instantly recalculate the preliminary comp-based ARV.
- Added a one-click Comparable Sales PDF report.
- Updated visible version and PWA cache to Version 6.8.

IMPORTANT
- Continue using the same RentCast API key. No second API key is required.
- The map needs internet access and location coordinates returned by RentCast.
- The comp-based ARV is preliminary. The system cannot guarantee that a comparable was renovated; review condition before relying on the ARV.
- Upload every file in this folder to the ROOT of the existing GitHub repository and replace the existing files.
