BEARCREST CRM — VERSION 9.3

This build keeps the Version 6 mobile design language while upgrading the complete CRM shell for phone, Galaxy Fold, tablet, Samsung DeX, Windows, Edge, and Chrome.

PRESERVED WORKING FEATURES
- Dashboard and loan pipeline
- Contacts and follow-ups/tasks
- Calendar and closing dates
- Lender management
- Document library and client uploads
- Google Drive loan folders
- Jotform application sync
- Archive and restore workflow
- Import/export and PWA installation
- Mobile field actions: call, text, map, note, and camera scan

9.3 UPGRADES
- Updated Version 9.3 identity and PWA cache
- Premium green-and-gold visual polish without changing the favorite layout
- Improved responsive behavior for Fold, tablet, DeX, and smaller laptops
- Larger touch targets and safer mobile spacing
- Stronger cards, navigation states, focus states, and standalone-app behavior
- Existing local CRM data remains under the same storage structure

INSTALLATION
Upload all files in this folder to the new GitHub repository or replace the existing repository files. Then deploy through GitHub Pages. For Google Drive/Jotform connectivity, deploy BearCrest_Cloud_Connector.gs as a Google Apps Script web app and paste its URL into CRM Settings.
